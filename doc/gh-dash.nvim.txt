1. INTRODUCTION                                               *gh-dash-intro*

gh-dash.nvim provides a floating terminal window to run the `gh-dash` TUI
(https://github.com/dlvhdr/gh-dash) directly inside Neovim. The terminal
session persists in the background when the window is hidden, and can be
toggled back at any time.

==============================================================================
2. REQUIREMENTS                                        *gh-dash-requirements*

- Neovim >= 0.10
- `gh` CLI (https://cli.github.com/)
- `gh-dash` extension: `gh extension install dlvhdr/gh-dash`

==============================================================================
3. INSTALLATION                                        *gh-dash-installation*

Using lazy.nvim: >lua

  {
    'johnseth97/gh-dash.nvim',
    lazy = true,
    keys = {
      {
        '<leader>cc',
        function() require('gh_dash').toggle() end,
        desc = 'Toggle gh-dash popup',
      },
    },
    opts = {
      border      = 'rounded',
      width       = 0.8,
      height      = 0.8,
      autoinstall = true,
    },
  }
<

==============================================================================
4. CONFIGURATION                                          *gh-dash-config*

Call `require('gh_dash').setup(opts)` with a table containing any of the
following fields:

`keymaps`       table                                  *gh-dash-config-keymaps*
                Table with optional `toggle` key specifying a normal-mode
                keymap to toggle the popup.
                Default: `{}`

`border`        string|table                           *gh-dash-config-border*
                Border style for the floating window. Accepts:
                `'single'`, `'double'`, `'rounded'`, `'square'`, `'none'`,
                or a custom border table (see |nvim_open_win()|).
                Default: `'single'`

`width`         number                                 *gh-dash-config-width*
                Width of the floating window as a fraction of editor columns.
                Default: `0.8`

`height`        number                                 *gh-dash-config-height*
                Height of the floating window as a fraction of editor lines.
                Default: `0.8`

`cmd`           string|string[]                        *gh-dash-config-cmd*
                Command to run in the terminal buffer.
                Default: `{ 'gh', 'dash' }`

`autoinstall`   boolean                                *gh-dash-config-autoinstall*
                When `true`, automatically installs the `gh-dash` extension
                via `gh extension install dlvhdr/gh-dash` if not found.
                Default: `false`

==============================================================================
5. COMMANDS                                              *gh-dash-commands*

:GHdash                                                            *:GHdash*
                Toggle the gh-dash floating popup.

:GHdashToggle                                                *:GHdashToggle*
                Alias for |:GHdash|.

==============================================================================
6. LUA API                                                  *gh-dash-api*

require('gh_dash').setup({opts})                         *gh_dash.setup()*
                Configure the plugin. Creates user commands and optional
                keymaps. Must be called before using the plugin.

require('gh_dash').open()                                 *gh_dash.open()*
                Open the gh-dash floating terminal. If already open, focuses
                the existing window.

require('gh_dash').close()                               *gh_dash.close()*
                Close the gh-dash window and delete the terminal buffer.

require('gh_dash').toggle()                             *gh_dash.toggle()*
                Toggle the popup visibility. Hides the window (keeping the
                job alive) if visible; re-shows if hidden; opens fresh if
                the buffer was destroyed.

require('gh_dash').statusline()                     *gh_dash.statusline()*
                Returns `'[gh_dash]'` when a job is running in the
                background (window hidden), otherwise `''`.

require('gh_dash').status()                             *gh_dash.status()*
                Returns a lualine component table. See |gh-dash-lualine|.

==============================================================================
7. LUALINE INTEGRATION                                    *gh-dash-lualine*

Add the component to your lualine configuration: >lua

  table.insert(opts.sections.lualine_x, require('gh_dash').status())
<

This shows a gear icon with `[gh_dash]` when the terminal is running in the
background.

==============================================================================
8. HEALTH CHECK                                            *gh-dash-health*

Run `:checkhealth gh_dash` to verify that all dependencies are installed and
properly configured.
